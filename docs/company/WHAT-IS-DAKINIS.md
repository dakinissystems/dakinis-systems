# Qué es Dakinis (narrativa comercial)

> **Para humanos externos** (amigos, clientes, inversores). Técnico → [`../ARCHITECTURE.md`](../ARCHITECTURE.md) · Mensaje canónico → [`MESSAGING.md`](./MESSAGING.md)

## Frase oficial (≤30 segundos)

**Dakinis Systems** es una plataforma de software que reúne herramientas para **gestionar, automatizar y conectar** negocios y comunidades desde un mismo ecosistema — con un solo login y un escritorio llamado **Hub**.

No somos “cuatro webs sueltas” ni una software factory. Vendemos **producto SaaS modular**.

---

## Arquitectura comercial (lo que ve el cliente)

```
                    DAKINIS SYSTEMS
                 Software conectado
                          │
          ┌───────────────┼────────────────┐
          │               │                │
       NEGOCIOS        CREADORES       COMUNIDADES
          │               │                │
     Dakinis One    StreamAutomator     AkoeNet
   (gestión + ops)  (streams / auto)   (comunidad)
          │
       + LifeFlow (finanzas personales)
       + Tabletop (gaming) — MVP
          │
          └───────────────┬────────────────┘
                          │
                     DAKINIS HUB
                   (Mi día · Attention)
                          │
             AI · Billing · Notifications · Identity
```

| Producto | Para quién | Una línea |
|----------|------------|-----------|
| **Dakinis One** | Empresas / locales / cadenas | CRM, ventas, inventario y operaciones (hospitality) con módulos según plan |
| **StreamAutomator** | Creadores / streamers | Automatiza lo que ocurre alrededor de tus streams (programa, anuncia, IF/THEN) |
| **AkoeNet** | Comunidades | Comunidad integrada con el ecosistema Dakinis (no “otro Discord”) |
| **LifeFlow** | Personas / freelancers | Finanzas personales y score |
| **Tabletop** | Jugadores | Juegos de mesa (MVP) |

---

## Golden Path (onboarding oficial)

El único camino que prometemos al cliente nuevo:

```
Landing → Registro → Workspace → Hub (Mi día) → Dakinis One
  → CRM / Ventas / Inventario → Hospitality (si aplica)
  → Valor diario → Plan → Pagar → Retención
```

LifeFlow, StreamAutomator, AkoeNet y Tabletop son **ecosistema**, no requisito del primer día.
