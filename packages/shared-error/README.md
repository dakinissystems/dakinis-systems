# `@dakinis/shared-error`

Helpers de error operacional (`AppError`) y mapeo HTTP/Express para servicios Dakinis.

## Install (GitHub Packages)

```bash
# requiere NODE_AUTH_TOKEN con read:packages
npm install @dakinis/shared-error@0.1.0
```

Ver `packages/.npmrc.example`.

## Publish

- Manual: `workflow_dispatch` → **Publish shared-error**
- Tag: `shared-error-v0.1.0`
