# `@dakinissystems/shared-error`

Helpers de error operacional (`AppError`) y mapeo HTTP/Express para servicios Dakinis.

## Install (GitHub Packages)

```bash
# requiere NODE_AUTH_TOKEN con read:packages
npm install @dakinissystems/shared-error@0.1.0
```

Ver `packages/.npmrc.example`. Scope = org GitHub (`dakinissystems`), no `@dakinis`.

## Publish

- Actions → **Publish Dakinis package** → `package=shared-error`
- Tag: `shared-error-v0.1.0`
